## map 和 filter

````python
map(function, iterable)
filter(function, iterable)
````

map：将function应用到iterable的每个值上

filter：过滤iterable，如果function完后的结果是True就保留

这两个函数返回的都是一个迭代器，不是list，且只在被调用时才会计算，计算完后立马释放内存，避免内存占用过多。

其实可以用列表推导式代替：

````python
map(lambda x : x * 2, nums)
==
[x * 2 for x in nums]

filter(lambda x : x % 2 == 0, nums)
==
[x for x in nums if x % 2 == 0]
````

# 抽象屏障 Abstraction Barriers

将功能的使用和功能的具体实现**严格**分隔开，每一层的功能只能用这一层的函数实现，不能跨层级，将前面一层的所有功能视为一个抽象

| Parts of program that ...       | using ...(这些是前面一层实现好了封装好了的，给当前这一层用)          |
| ------------------------------- | -------------------------------------------- |
| 使用有理数进行运算              | mul_rational, add_rational, print_rational等 |
| 创建有理数 或者实现有理数的操作 | rational, numer, denom |
| 实现选择器和构造器 | list literals and element selection(字面量、索引) |

❌错误：

````python
add_rational([1, 2], [1, 4])//没用constructor
def divide_rational(x, y):
    return [x[0] * y[1], x[1] * y[0]]
//返回时没用selector和constructor
````

✔例:

````python
from fraction import gcd
def rational(n, d):
    g = gcd(n, d) #最大公因数
    return [n // g, d // g]
````

在对有理数运算时结果可能不是最简，我们不需要对add_rational, mul_rational这些进行修改，我们只需要修改构造函数就行

### Tree的实现

与tree相关的实现基本都要使用**递归**

````python
def tree(label, branches = []):
    for branch in branches:
        assert is_tree(branch), 'branch must be a tree'
    return [label] + list(branches)

def label(tree):
    return tree[0]

def branches(tree):
    return tree[1:]

def is_tree(tree):
    if type(tree) != list or len(tree) < 1:
        return False 
    for branch in branches(tree):
        if not is_tree(branch):
            return False
    return True

def is_leaf(tree):
    return not branches(tree)
````

例

````python
def fib_tree(n):
    if n <= 1:
        return tree(n)
    else:
        left, right = fib_tree(n - 2), fib_tree(n - 1)
        return tree(label(left) + label(right), [left, right])
````

处理tree

````python
def count_leaves(t):
    """count the leaves of a tree"""
    if is_leaf(t):
        return 1
    else:
        branch_counts = [count_leaves(b) for b in branches(t)]
        return sum(branch_counts)
````

````python
def increment(t):
    """返回一个tree，这个tree的每个label都++"""
    return tree(label(t) + 1, [increment(b) for b in branches(t)])
#当是leaf时，leaf也属于tree，所以不用考虑基本情况
````

````python
def print_tree(t, indent = 0):
    print(' ' * indent + str(label(t)))
    for b in branches(t):
        print_tree(b, indent + 1)
````

````python
def print_sums(t, so_far):
    so_far += label(t)
    if is_leaf(t):
        print(so_far)
    else :
        for b in branches(t):
            print_sums(b, so_far)
````

# 可变函数 Mutable Function

## 一种方法：列表(可变对象)

list是可变对象，作为形参传入函数时是引用的，可修改原list

每一次调用，即使传入相同参数，也可能有不同结果

（通过在函数中使用父环境中的可变对象实现）



````python
##取款函数
def make_withdraw_list(balance):
    b = [balance]
    def withdraw(amount):
        if amount > b[0]:
            return 'Insufficient funds'
        b[0] -= amount
        return b[0]
    return withdraw
#这个b是在withdraw函数的父环境里的，所以修改会带到下一次调用

withdraw = make_withdraw_list(100)
>>> withdraw(25)

>>> withdraw(25)

````

## 另一种方法：nonlocal

````python
def make_withdraw_list(balance):
    b = balance
    def withdraw(amount):
        nonlocal b #重要！！！
        if amount > b:
            return 'Insufficient funds'
        b -= amount #这里重新绑定了b
        return b
    return withdraw
````

python不能对没有在这个**帧**定义的名字重新绑定，但是可以使用使用**nonlocal**告诉解释器，我想修改前面父环境的这个名字

###### 为什么可变对象可以呢？

因为对于可变对象，你改了b[0]，这个列表还是这个列表，只是元素变了而已，b还是绑定到这个列表，所以没有重绑定的问题

````python
def make_withdraw_list(balance):

````

# Iterator 迭代器

一个指向可迭代值的某个位置的对象

iter(iterable):返回可迭代值的元素的迭代器

next(iterator):返回迭代器的下一个元素

````python
>>> s = [3, 4, 5]
>>> t = iter(s) #此时这个迭代器指在0位置的前面
>>> next(t)
3
>>> list(t)
[4, 5] #这个操作使迭代器走完剩下的元素，所以会使迭代器走到最末端，会修改指向位置
````

- 可迭代值iterable value就是可以传递给iter函数来创建迭代器的值（iterator自身也是iterable）
- 所有迭代器都是可变对象，当调用next时就会变异到下一个位置
- 字典的key、值、item(一个键值对)都是可迭代值

### 字典与迭代器


### 迭代器相关函数

许多返回迭代器的python内置函数以**惰性方式**计算，即只在被请求是计算结果

map(func, iterable)：应用f到迭代器中的每个x

filter(func, iterable)：迭代x如果x满足f

zip(first_iter, second_iter):迭代共同索引的(x, y)对

reversed(sequence)：返回反向遍历的迭代器

上述迭代器在调用next()时会返回如上结果

# Generators 生成器


生成器函数是惰性计算的

### 生成器和迭代器

生成器函数返回迭代器，但在执行过程中它常常处理迭代器

#### Generators can Yield from Iterators

**yield from**语句从迭代器或可迭代对象中产生(yield)**所有**值

````python
def a_then_b(a, b):
    for x in a :
        yield x
    for x in b :
        yield x
#等价于
def a_then_b(a, b):
    yield from a
    yield from b
````

yield from可递归

````python
def countdown(k):
    if k > 0:
        yield k
        yield from countdown(k - 1)
````

````python
def prefixes(s):
    if s:
        yield from prefixes(s[:-1])
        yield s
def substrings(s):
    if s:
        yield from prefixes(s)
        yield from substrings(s[1:])
        
>>> list(prefixes('tops'))
['t', 'to', 'top', 'tops']
        
>>> list(substrings('tops'))
['t', 'to', 'top', 'tops', 'o', 'op', 'ops', 'p', 'ps', 's']
````

### 数字分割

一般写法

````python 
def list_partitions(n, m):
    if n < 0 or m == 0:
        return []
    else :
        exact_match = []
        if n == m :
        	exact_match = [[m]]
        with_m = [p + [m] for p in list_partitions(n - m, m)]
        without_m = [p for p in list_partitions(n, m - 1)]
        return exact_match + with_m + without_m
    
>>> for p in list_partitions(6, 4):
    	print(p)
[2, 4]
[1, 1, 4]
[3, 3]
[1, 2, 3]
[1, 1, 1, 3]
[2, 2, 2]
[1, 1, 2, 2]
[1, 1, 1, 1, 2]
[1, 1, 1, 1, 1, 1]
````

使用yield：

````python
def list_partitions(n, m):
    if n > 0 and m > 0:
        if n == m:
            yield str(m)
        for p in list_partitions(n - m, m):
            yield p + '+' + str(m)
        yield from list_partitions(n, m - 1)
````

#### list函数

list函数创造一个新list

#### slice作为左值

slice作为左值会修改原list

````python
s[0:0] = t
#s -> [5, 6, 2, 3]
s[3:] = t
#s -> [5, 6, 2, 5, 6]
t[1] = 0
#不会改变s

s = [3, 4]
s[0:1] = []
#s -> [3]
````

#### pop

````python
t = s.pop()
# t -> 3 s-> [2]
````

#### remove

删除右边开始第一个等于参数的元素

````python
t.extend(t)
#t -> [6, 5, 6, 5]
t.remove(5)
#t -> [6, 5, 6]
````
