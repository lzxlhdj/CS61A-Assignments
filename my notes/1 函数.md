# 帧和环境

## 帧

在 Python 中，对一个表达式求值的环境由一系列**帧**（frame）组成，我们通常把帧画成一个个方框。每个帧里存放着一系列的**绑定**（binding）：名称 → 对应的值。存在一个单独的**全局帧**（global frame）。赋值和导入语句都会往当前环境的第一个帧里添加绑定。

在**嵌套定义**中，函数值的父级是定义该函数的环境的第一帧。在全局环境中定义的函数没有父级或者父级为全局。当调用用户定义的函数时，创建的帧与该函数具有相同的父级。

````python
def square(x):
    return x * x

def make_adder(n):
    def adder(k):
        return k + n
    return adder

def compose1(f, g):
    def h(x)：
    	return f(g(x))
    return h

compose1(square, make_adder(2))(3)
````



![image-20260112164122872](.\screenshot\image-20260112164122872.png)

如图红色和黄色下划线最后的成为**父级注释**，标注了该函数的父级。

## 环境

环境为一系列帧所组成的链条。如图**蓝色和绿色**的即为环境。帧链的顺序和创建帧的顺序相反。在评估某个变量的值时，会在其所在环境进行评估，就是顺着环境这条链一个一个帧往前查找。

## 闭包

这是python封装函数的方式。函数封装的是定义时的环境。因此在求值时是可以访问其父环境中的绑定的。其实有点像c++的类。

### lambda 表达式

在 Python 中，我们可以使用 lambda 表达式**临时创建**函数，这些表达式会计算为**未命名的函数**。一个 lambda 表达式的计算结果是一个函数，它仅有一个返回表达式作为主体。不允许使用赋值和控制语句。

````python
square = lambda x : x * x
````

这和

````python
def square(x):
    return x * x
````

几乎一模一样，只是在lambda中该函数是没有名字的，只被称为lambda。

### Currying 柯里化

将有多个参数的函数转化为一个只有一个参数的函数链

````python
def make_adder(n):
    return lambda k : k + n

>>> make_adder(2)(3)
5
>>> add(2, 3)
5
````

或者，抽象出来：

````python
def curry2(f):
    """将f，要两个参数，转化为g，接受两个单独的参数"""
    def g(x):
        def h(y):
            return f(x, y)
        return h
    return g
````

当然，也可以逆柯里化：

````python
def uncurry(g):
    def f(x, y):
        return g(x)(y)
    return f
````

### 短路

- and ： 
  1. 如果左值为false，整个为false，
  2. 否则评估右值，整个表达式为右值
- or :
  1. 如果左边为真值v，则整个为真值v
  2. 否则评估右值，整个为右值

注意：如果左边已满足要求会短路！不会评估右！

# 函数泛化 Generalize

````python
def identity(k):
    return k

def cube(k):
    return pow(k, 3)

def summation(n, term):
    """Sum the first N terms of a sequence
    >>> summation(5, cube)
    225
    """
    total, k = 0, 1
    while k <= n:
        total, k = total + term(k), k + 1
    return total

def sum_naturals(n):
    return summation(n, identity)

def sum_cube(n):
    return summation(n, cube)
````

如是将多个相加的函数泛化为一个函数模板

# 装饰器 Decorator

Python允许在函数f前面添加@g作为装饰器，实际执行效果为g(f(x))

例如：

````python
def trace(f):
    """在原本f的功能上添加一个print调用的功能，其他f功能不变
    """
    def g(x):
        print("Calling ",f,"to the value of ",x)
        return f(x)
    return g

@trace
def square(x):
    return x * x

print(square(2))
````

此时运行的结果为

````bash
Calling  <function square at 0x000002067349D080> to the value of  2
4
````

像这样写的trace函数可用在装饰器上进行debug

也可以使用多个@装饰器，从上往下进行符复合
